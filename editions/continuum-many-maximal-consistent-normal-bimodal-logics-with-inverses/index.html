Continuum many maximal consistent normal bimodal logics with inverses

Timothy Williamson

Notre Dame Journal of Formal Logic 39 (1) (1998): 128–134.

Abstract

The paper considers extensions of a normal bimodal logic KL in which the two necessity operators are mutual one-sided inverses. A continuum of maximal consistent normal extensions of KL is constructed, each of which has infinitely many quasi-normal Post complete extensions. Some syntactic properties of maximal consistent normal bimodal logics and in particular of such extensions of KL are investigated.

There are just two maximal consistent normal monomodal logics; each consistent normal monomodal logic is extended by at least one of them (see Makinson [2]). In bimodal logic, the situation is less simple. This note investigates one aspect of the problem by considering maximal consistent normal bimodal logics in which the two modal operators are one-sided inverses of each other, that is, □■α ≡ α is a theorem for every formula α. It will be shown that there are 2ℵ02^{\aleph_0} such logics. For a general account of bimodal logics in which the two modal operators are one-sided inverses of each other see Humberstone and Williamson [1].

Some terminology for bimodal logic will briefly be rehearsed. The language consists of a set of sentence letters p, . . . , the 0-place falsity constant ⊥, the material implication ⊃, and two 1-place operators □ and ■. None of the results in this paper essentially depends on the cardinality of the set of sentence letters (even if it is 0). Other standard logical symbols are used as metalinguistic abbreviations; ◊\lozenge = ¬□¬ and ⬧\blacklozenge = ¬■¬. A letterless formula is one not containing sentence letters. A letterless substitution maps all sentence letters to letterless formulas.

A logic is a set of formulas containing all truth-functional tautologies and closed under uniform substitution (US) and modus ponens (MP). If Σ is a logic, we say ⊢Σα\vdash_\Sigma \alpha when α∈Σ\alpha \in \Sigma. A normal (bimodal) logic is a logic containing all formulas of the forms □(α ⊃ β) ⊃ (□α ⊃ □β) and ■(α ⊃ β) ⊃ (■α ⊃ ■β) and closed under RN□\mathrm{RN}_{□}(α/□α) and RN■\mathrm{RN}_{■}(α/■α). Σ is inconsistent if and only if ⊥ ∈ Σ. Σ is Post complete if and only if Σ is a consistent logic and for every consistent logic Σ+\Sigma^{+}, if Σ ⊆ Σ+\Sigma^{+} then Σ = Σ+\Sigma^{+} (Segerberg [3], corrected in Segerberg [4], discusses Post completeness in monomodal logic). Σ is a maximal consistent normal logic if and only if Σ is a consistent normal logic and for every consistent normal logic Σ+\Sigma^{+}, if Σ ⊆ Σ+\Sigma^{+} then Σ = Σ+\Sigma^{+}. Proposition 5 below illustrates the difference between Post completeness and maximal consistent normality. Following [1], the smallest normal logic containing □■α ≡ α for all α is KL.

A necessitation is a sequence (possibly null) of occurrences of □ and ■ in any order.

Since KL is normal, ⊢𝐊𝐋□(⬧α⊃■α)\vdash_{{𝐊𝐋}}□(\blacklozenge\alpha\supset■\alpha). Since KL ⊆ Σ, ⊢Σ□(⬧α⊃■α)\vdash_\Sigma□(\blacklozenge\alpha\supset■\alpha). By Corollary 10, ⊢Σ⬧α⊃■α\vdash_\Sigma\blacklozenge\alpha\supset■\alpha. □

Proposition 13 If a maximal consistent normal extension Σ\Sigma of 𝐊𝐋{𝐊𝐋} is satisfiable on a finite frame, then ⊢Σ□α≡α\vdash_\Sigma□\alpha\equiv\alpha and ⊢Σ■α≡α\vdash_\Sigma■\alpha\equiv\alpha.

Proof: Suppose that a maximal consistent normal extension Σ of KL is satisfiable on a finite frame ⟨W, R, S⟩. The ■-fragment of a bimodal logic Σ is the result of replacing ■ by □ throughout the set of all formulas in Σ not containing □ (the replacement is for notational uniformity with standard monomodal logic). If Σ is (bi)normal, its ■-fragment is a normal monomodal logic. We determine the ■-fragments of all maximal consistent normal extensions of KL. Let Triv be the smallest normal monomodal logic containing all formulas of the form □α ≡ α and 𝐊𝐃c{𝐊𝐃}_c the smallest normal monomodal logic containing all formulas of the form ◊\lozengeα ⊃ □α.

Proposition 14 If Σ\Sigma is a maximal consistent normal extension of 𝐊𝐋{𝐊𝐋}, then the ■-fragment of Σ\Sigma is either 𝐊𝐃c{𝐊𝐃}_c or 𝑇𝑟𝑖𝑣\mathit{Triv}.

Proof: Let Δ be the ■-fragment of Σ. By Corollary 11, 𝐊𝐃c{𝐊𝐃}_c ⊆ Δ. Thus either Δ = 𝐊𝐃c{𝐊𝐃}_c or Δ is a proper normal extension of 𝐊𝐃c{𝐊𝐃}_c. In the latter case, ⊢Δ□i◊⊤\vdash_\Delta□^i\lozenge \top for some i (Segerberg [5]). Then ⊢Σ■i⬧⊤\vdash_\Sigma■^i\blacklozenge\top, so ⊢Σ□i■i⬧⊤\vdash_\Sigma□^i■^i\blacklozenge\top, so ⊢Σ⬧⊤\vdash_\Sigma\blacklozenge\top since Σ extends KL, so ⊢Σ■α≡α\vdash_\Sigma■\alpha\equiv\alpha for all α by Corollary 8, so Triv ⊆ Δ. Hence Δ = Triv, for the only proper normal extension of Triv is inconsistent. □

The more difficult problem of finding the □-fragments of all maximal consistent normal extensions of KL is left open.
