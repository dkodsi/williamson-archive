A relation between namesakes in modal logic

Timothy Williamson

Bulletin of the Section of Logic 20 (3/4) (1991): 129–137.

Abstract

The closure under a certain rule of the modal system usually called “K4K4” is shown to be the modal system called “K4K4” by Sobociński.

A modal system SS provides double cancellation iff for all sentences AA and BB, if ⊢SLA≡LB\vdash_S LA \equiv LB and ⊢SMA≡MB\vdash_S MA \equiv MB then ⊢SA≡B\vdash_S A \equiv B. It is of course not required that ⊢S((LA≡LB)&(MA≡MB))⊃(A≡B)\vdash_S ((LA \equiv LB) \mathbin{\&} (MA \equiv MB)) \supset (A \equiv B). If SS is any modal system, there is a smallest normal extension S+S+ of SS providing double cancellation (terminology as in [1]). For reasons given in [3], the double cancellation rule may be of some philosophical interest. This note extends the results of [3] and [4] on double cancellation in normal systems.

The name “K4K4” is ambiguous. It is now customarily used for the smallest normal system containing the schema LA⊃LLALA \supset LLA; this practice is followed here. Sobociński used the same name for the smallest system containing KT4KT4 (= S4S4) and the schemata A⊃(MLA⊃LA)A \supset (MLA \supset LA) and MLA≡LMAMLA \equiv LMA ([2]); this normal system is here referred to as K4SobK4_{Sob}. The relation to be established between these namesakes is that K4+=K4SobK4+ = K4_{Sob}; it will also be shown that K4SobK4_{Sob} is the only normal extension of K4K4 providing double cancellation in which there is not modal collapse. This extends the results of [3], in which it was shown that KD4!+=K4SobKD4!+ = K4_{Sob}, where KD4!KD4! is the smallest normal system containing the formula MTMT (TT being a constant tautology) and the schema LLA≡LALLA \equiv LA, and [4], in which it is shown that KW+KW+ is inconsistent, where KWKW is “provability logic”, the smallest normal system containing L(LA⊃A)⊃LAL(LA \supset A) \supset LA, an extension of K4K4.

Lemma E. K4+=K4SobK4+ = K4_{Sob}.

Proof. It is shown in [3] that KD4!+=K4SobKD4!+ = K4_{Sob}. By Lemmas C and D, KD4!⊆K4+KD4! \subseteq K4+, so KD4!+⊆K4++=K4+KD4!+ \subseteq K4++ = K4+. But K4⊆KD4!K4 \subseteq KD4!, so K4+⊆KD4!+K4+ \subseteq KD4!+.

Lemma F. The only normal proper extensions of K4SobK4_{Sob} are 𝑇𝑟𝑖𝑣\mathit{Triv} (KK plus A≡LAA \equiv LA) and the inconsistent system.

Proof. Let SS be any normal extension of K4SobK4_{Sob}. By results noted in [3], the frame of any generated submodel of the canonical model of K4SobK4_{Sob} consists of either a single reflexive point or two non-simmetrically related reflexive points, and K4SobK4_{Sob} is valid on all and only such frames. Since any non-theorem of SS is falsified in a generated submodel of the canonical model of K4SobK4_{Sob} that is a model of SS, SS has the finite model property, and so by Corollary 8.14 of [1] is characterized by a class CC of frames, each of must be of one of the two mentioned kinds (else it would not be a frame for K4SobK4_{Sob}, and so not for SS). If CC contains a two-point frame, S=K4SobS = K4_{Sob}. If CC is non-empty but contains only one-point frames, S=𝑇𝑟𝑖𝑣S = \mathit{Triv}. If CC is empty, SS is inconsistent.

Theorem. The normal extensions of K4K4 providing double cancellation are K4SobK4_{Sob}, 𝑇𝑟𝑖𝑣\mathit{Triv} and the inconsistent system.

Proof. Any normal extension of K4K4 providing double cancellation is one of the three mentioned systems by Lemmas E and F. K4SobK4_{Sob} provides double cancellation by Lemma E. 𝑇𝑟𝑖𝑣\mathit{Triv} and the inconsistent system provide it trivially.
