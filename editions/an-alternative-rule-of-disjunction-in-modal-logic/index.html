An alternative rule of disjunction in modal logic

Timothy Williamson

Notre Dame Journal of Formal Logic 33 (1) (1992): 89–100.

Abstract

Lemmon and Scott introduced the notion of a modal system’s providing the rule of disjunction. No consistent normal extension of KB provides this rule. An alternative rule is defined, which KDB, KTB, and other systems are shown to provide, while K and other systems provide the Lemmon–Scott rule but not the alternative rule. If SS provides the alternative rule then either ∼A\mathord{\sim} A is a theorem of SS or AA is whenever A→□AA \to □ A is a theorem; the converse fails. It is suggested that systems with this property are appropriate for handling sorites paradoxes, where □□ is read as ‘clearly’. The S4 axiom fails in such systems.

Lemmon and Scott introduced the notion of a modal system’s providing the rule of disjunction ([6], p. 44). This paper investigates similar rules for systems that do not provide the rule of disjunction. It ends with an application to philosophical issues about vagueness and sorites paradoxes.

First, some definitions. For any wff AA, □0A=A□^0 A=A; □j+1A=□j□A□^{j+1}A=□^j□ A. SS is a modal system.

SS provides the Lemmon–Scott rule of disjunction:

if
⊢S□A1∨…∨□An\vdash_S □ A_1 \vee \ldots \vee □ A_n
then
⊢SAi\vdash_S A_i for some ii (1≤i≤n1 \le i \le n).

SS provides the weak rule of disjunction:

if
⊢S□j1A1∨…∨□jnAn\vdash_S □^{j_1}A_1 \vee \ldots \vee □^{j_n}A_n for all j1,…,jnj_1,\ldots,j_n (≥0\ge 0)
then
⊢SAi\vdash_S A_i for some ii (1≤i≤n1 \le i \le n).

SS provides the bad rule of disjunction:

if
⊢SA0∨□A1∨…∨□An\vdash_S A_0 \vee □ A_1 \vee \ldots \vee □ A_n
then
⊢SAi\vdash_S A_i for some ii (0≤i≤n0 \le i \le n).

SS provides the alternative rule of disjunction:

if
⊢SA0∨□j1A1∨…∨□jnAn\vdash_S A_0 \vee □^{j_1}A_1 \vee \ldots \vee □^{j_n}A_n for all j1,…,jnj_1,\ldots,j_n (≥0\ge 0)
then
⊢SAi\vdash_S A_i for some ii (0≤i≤n0 \le i \le n).

Of course, the weak and alternative rules have infinitary premises, but then the Lemmon–Scott rule itself is not supposed to be a rule of proof within modal systems but a metalogical property of them. For present purposes, a modal system is simply a set of theorems; amongst the admissible rules for such a system, no particular subset will be marked off as derivable within a privileged apparatus for proving theorems (Humberstone [5] makes further refinements). As for the distinction between finitary and infinitary rules, the systems to be considered that satisfy the infinitary rules above will also be seen to satisfy finitary versions of them, with jij_i bounded by the modal depth of A0,…,AnA_0,\ldots,A_n.

Discussion will be confined to normal systems (Hughes and Cresswell [4], pp. 4–6). The following axioms will be mentioned: B (p→□◊pp\to□\lozenge p), D (□p→◊p□ p\to\lozenge p), D! (□p↔◊p□ p\leftrightarrow\lozenge p), E (◊p→□◊p\lozenge p\to□\lozenge p), G1 (◊□p→□◊p\lozenge□ p\to□\lozenge p), T (□p→p□ p\to p), W (□(□p→p)→□p□(□ p\to p)\to□ p), 4 (□p→□□p□ p\to□□ p).

Trivially, if SS provides either the Lemmon–Scott or the alternative rule then it provides the weak rule. It will be noted that the weak and Lemmon–Scott rules are equivalent for extensions of KT4 (= S4), in which ⊢S□A1∨…∨□An\vdash_S □ A_1\vee\ldots\vee□ A_n entails ⊢S□j1A1∨…∨□jnAn\vdash_S □^{j_1}A_1\vee\ldots\vee□^{j_n}A_n for all j1,…,jnj_1,\ldots,j_n. Similarly, the bad and alternative rules are equivalent for extensions of KT4. The main interest will be in systems providing the alternative but not the Lemmon–Scott rule. The bad rule is included only for symmetry; it is so-called because no consistent normal system provides it (from ⊢S∼□p∨□p\vdash_S \mathord{\sim}□ p\vee□ p it yields ⊢S∼□p\vdash_S\mathord{\sim}□ p or ⊢Sp\vdash_Sp), although K and other systems provide it in the special case when A0A_0 contains no modal operators ([6], p. 47).

Well-known examples of systems providing the Lemmon–Scott rule are K, KD (= D), KT (= T), K4, KD4, KT4, and KW ([6], pp. 46, 79–81; [4], pp. 100–101). But no consistent normal extension of KG1 provides the Lemmon–Scott rule; for any such system SS, ⊢S□◊∼p∨□◊p\vdash_S□\lozenge\mathord{\sim} p\vee□\lozenge p but neither ⊢S◊∼p\vdash_S\lozenge\mathord{\sim} p nor ⊢S◊p\vdash_S\lozenge p. Since B and E entail G1 in normal systems, no consistent normal extension of KB or of KE provides the rule; for example, KTE (= S5) does not. The argument can be adapted to show that no consistent normal extension of K4G1 provides the weak rule. For if SS extends K4G1, ⊢S□i□◊∼p∨□j□◊p\vdash_S□^i□\lozenge\mathord{\sim} p\vee□^j□\lozenge p for all i,j≥0i,j\ge0, so ⊢S□◊∼p\vdash_S□\lozenge\mathord{\sim} p or ⊢S□◊p\vdash_S□\lozenge p if SS provides the weak rule. By substitution, ⊢S□◊∼(p∨∼p)\vdash_S□\lozenge\mathord{\sim}(p\vee\mathord{\sim} p). Since SS is normal, ⊢S∼◊∼(p∨∼p)\vdash_S\mathord{\sim}\lozenge\mathord{\sim}(p\vee\mathord{\sim} p) and so ⊢S□A\vdash_S□ A for any AA. Thus ⊢S□i∼p∨□jp\vdash_S□^i\mathord{\sim} p\vee□^jp if i>0i>0 or j>0j>0. Since ⊢S∼p∨p\vdash_S\mathord{\sim} p\vee p, ⊢S□i∼p∨□jp\vdash_S□^i\mathord{\sim} p\vee□^jp for all i,j≥0i,j\ge0, so ⊢S∼p\vdash_S\mathord{\sim} p or ⊢Sp\vdash_Sp by the weak rule again, making SS inconsistent. Similarly, no consistent normal extension of KE provides the weak rule, for it is not hard to show that ⊢KE□i□(∼p&p)∨□j◊∼p∨□k◊p\vdash_{KE}□^i□(\mathord{\sim} p\mathbin{\&} p)\vee□^j\lozenge\mathord{\sim} p\vee□^k\lozenge p for all i,j,ki,j,k.

KG1 and KB can be shown not to provide the weak rule by a different route. More generally, if SS extends KG1 and provides the weak rule, SS extends KDG1, as neither KG1 nor KB does. For ⊢K□i□(∼p&p)∨◊(∼p∨p)\vdash_{\mathrm{K}}□^i□(\mathord{\sim} p\mathbin{\&} p)\vee\lozenge(\mathord{\sim} p\vee p) and ⊢KG1□i+1◊(∼p∨p)\vdash_{\mathrm{KG1}}□^{i+1}\lozenge(\mathord{\sim} p\vee p) for all ii, so ⊢KG1□i□(∼p&p)∨□j◊(∼p∨p)\vdash_{\mathrm{KG1}}□^i□(\mathord{\sim} p\mathbin{\&} p)\vee□^j\lozenge(\mathord{\sim} p\vee p) for all i,ji,j; thus if SS extends KG1 and provides the weak rule, ⊢S□(∼p&p)\vdash_S□(\mathord{\sim} p\mathbin{\&} p) or ⊢S◊(∼p∨p)\vdash_S\lozenge(\mathord{\sim} p\vee p). In the former case, ⊢S□i∼p∨□jp\vdash_S□^i\mathord{\sim} p\vee□^jp for all i,ji,j, so ⊢S∼p\vdash_S\mathord{\sim} p or ⊢Sp\vdash_Sp by another application of the rule, making SS inconsistent. In either case, SS extends KDG1.

In contrast, although KDG1, KTG1, KDB, and KTB do not provide the Lemmon–Scott rule they do provide the alternative rule and therefore the weak one. One might say that these systems are less deeply disjunctive than are K4G1 and KE (a system is disjunctive insofar as it cannot decide between the disjuncts of its disjunctive theorems).

That the alternative rule is stronger than the weak one can be seen already from the cases of K, K4, and KW. They provide the Lemmon–Scott rule and therefore the weak one. They do not provide the alternative rule, since any normal system providing it extends KD, as they do not. For if SS is normal, ⊢S◊(∼p∨p)∨□i□(∼p&p)\vdash_S\lozenge(\mathord{\sim} p\vee p)\vee□^i□(\mathord{\sim} p\mathbin{\&} p) for all ii, so ⊢S◊(∼p∨p)\vdash_S\lozenge(\mathord{\sim} p\vee p) or ⊢S□(∼p&p)\vdash_S□(\mathord{\sim} p\mathbin{\&} p); by an earlier argument, SS extends KD. One might say that systems providing both the Lemmon–Scott and the alternative rule, such as KD and KT, are more thoroughly nondisjunctive than are K, K4, and KW.

Problem Find a normal system providing the weak but neither the Lemmon–Scott nor the alternative rule.

A sufficient condition for a normal system SS to provide the Lemmon–Scott rule is that there be a class CC of generated models such that every nontheorem of SS is false at a generating world of some model in CC and an amalgamation of any finite subset of CC is a model for SS ([4], p. 99). An amalgamation of a set of models is their union together with an extra world from which all other worlds are accessible. The condition is sufficient because if ⊢SAi\vdash_S A_i for no ii, for each ii a model in CC can be chosen at some world in which AiA_i is false, falsifying □A1∨…∨□An□ A_1\vee\ldots\vee□ A_n at the extra world in the amalgamation of these models. Standard proofs that a system provides the rule of disjunction use this sufficient condition.

Many systems can be shown to provide the weak rule of disjunction by a similar construction, but now the extra world need only have the reflexive ancestral of the accessibility relation to the world falsifying AiA_i, since this suffices to falsify □j1A1∨…∨□jnAn□^{j_1}A_1\vee\ldots\vee□^{j_n}A_n for some j1,…,jnj_1,\ldots,j_n. This in turn permits a world falsifying A0A_0 to be used in place of the extra world, showing the system to provide the alternative rule.

The rule of margins signals a kind of expressive incompleteness in the systems which provide it. Suppose that □*□\text{*} is a (perhaps complex) operator in a normal modal system SS, where □*A□\text{*}A is to be interpreted as the infinite conjunction A&□A&□□A&…A\mathbin{\&}□ A\mathbin{\&}□□ A\mathbin{\&}\ldots. Thus SS should satisfy at least three conditions: (i) if ⊢SA\vdash_SA then ⊢S□*A\vdash_S□\text{*}A; (ii) ⊢S□*p→p\vdash_S□\text{*}p\to p; (iii) ⊢S□*p→□□*p\vdash_S□\text{*}p\to□□\text{*}p. If SS provides the rule of margins, either ⊢S□*p\vdash_S□\text{*}p or ⊢S∼□*p\vdash_S\mathord{\sim}□\text{*}p by (iii). If the former, ⊢Sp\vdash_Sp by (ii) and SS is inconsistent. If the latter, ⊢S∼□*(p∨∼p)\vdash_S\mathord{\sim}□\text{*}(p\vee\mathord{\sim} p) by substitution; but ⊢S□*(p∨∼p)\vdash_S□\text{*}(p\vee\mathord{\sim} p) by (i), and SS is again inconsistent. Thus a consistent normal system providing the rule of margins cannot express the ancestral of its own necessity operator. If an operator for the ancestral is introduced, the new system will not provide the rule of margins.

Now for the application. Some things are clearly heaps, some are clearly not heaps, and borderline cases are neither clearly heaps nor clearly not heaps (‘clearly’ could be taken epistemologically, semantically, or ontologically). □A□ A can be read as ‘It is clearly the case that AA’. That AA is a borderline case may be expressed as ∼□A&∼□∼A\mathord{\sim}□ A\mathbin{\&}\mathord{\sim}□\mathord{\sim} A. Let S?S? be an appropriate system of modal logic for this reading. The choice of a classical underlying propositional logic is controversial in the context of vagueness, but it may be motivated by either a supervaluational approach (Fine [3]) or the claim that clarity is an epistemological rather than a semantic or ontological matter (Cargile [2], Campbell [1], Sorensen [7]). Given classical logic, one cannot assert ‘If XX is a heap then XX is not a borderline case of a heap’ and ‘If XX is not a heap then XX is not a borderline case of a heap’ without abolishing the borderline cases altogether; rather, p&∼□pp\mathbin{\&}\mathord{\sim}□ p will be regarded as a consistent combination (pp atomic). To assume that S?S? is normal is to assume that the clear propositions are closed under logical consequence, but that need not be implausible: if XX is genuinely a borderline case of a heap, it surely follows that one cannot deduce from what is clear that XX is a heap, nor that it is not. It also seems plausible that if something is clearly the case, then it is the case. That makes S?S? at least as strong as KT.

Vagueness is often said to be ubiquitous in natural languages. One development of this idea would be the claim that it is never a matter of logic that all cases of AA are clear cases, unless for the trivial reason that it is a matter of logic that AA has no cases or that everything is a case of AA. In other words, if ⊢S?A→□A\vdash_{S?}A\to□ A then either ⊢S?∼A\vdash_{S?}\mathord{\sim} A or ⊢S?A\vdash_{S?}A. Thus the rule of margins can be taken to represent the ubiquity of vagueness. It is therefore satisfying that KT provides the rule, since on the present approach it is the minimal logic of clarity.

The claim formalized in the previous paragraph is not equivalent to the claim ‘It is a matter of logic that AA lacks borderline cases only when it is a matter of logic that AA has no cases or that everything is a case of AA’. The latter would be formalized by the rule that if ⊢S?□∼A∨□A\vdash_{S?}□\mathord{\sim} A\vee□ A then ⊢S?∼A\vdash_{S?}\mathord{\sim} A or ⊢S?A\vdash_{S?}A. This rule is a special case of the Lemmon–Scott rule of disjunction and is therefore possessed by systems such as K, K4, KD4, and KT4 that provide that rule but not the rule of margins. On the other hand, KD! provides the rule of margins but not the new rule, since ⊢KD!□∼p∨□p\vdash_{\mathrm{KD!}}□\mathord{\sim} p\vee□ p but neither ⊢KD!∼p\vdash_{\mathrm{KD!}}\mathord{\sim} p nor ⊢KD!p\vdash_{\mathrm{KD!}}p. However, the new rule follows easily from the rule of margins in extensions of KT, so the latter is the stronger rule in S?S? and therefore seems a more appropriate representation of the ubiquity of vagueness. The same point applies to the rule that if ⊢S?A→□A\vdash_{S?}A\to□ A and ⊢S?∼A→□∼A\vdash_{S?}\mathord{\sim} A\to□\mathord{\sim} A then ⊢S?∼A\vdash_{S?}\mathord{\sim} A or ⊢S?A\vdash_{S?}A, corresponding to the claim that all cases of AA are clear cases and all noncases clear noncases only if AA is a logical truth or falsehood. This rule is a consequence of both the previous one and the rule of margins and is equivalent to the former in extensions of KT. It says that when AA is not a logical truth or falsehood, its truth-conditions are liable to unclarity on at least one side; the rule of margins says that they are liable to unclarity on both sides.

The ubiquity of vagueness is relative to a language. If □*A□\text{*}A is introduced to mean that AA and clearly AA and clearly clearly AA and …, one must expect □*p→□□*p□\text{*}p\to□□\text{*}p to be a theorem of the new system and the rule of margins to fail, as noted above. This does not mean that KT is the wrong logic for clarity, of course, for what the rule of margins fails in may be a conservative extension of KT. There is no need to deny that precise sentences can be introduced into a so far thoroughly vague language. The rule of margins indicates that (with trivial exceptions) such sentences have not yet been introduced.

The connection between vagueness and the rule of margins can also be discerned in the proof of the theorem. In the case relevant to the rule, one takes a world at which AA holds and a world at which ∼A\mathord{\sim} A holds and constructs a sequence of worlds from one to the other, each accessible from its predecessor. The point is that there must be a cut-off point, a last world at which AA holds; A&∼□AA\mathbin{\&}\mathord{\sim}□ A will hold at that world. This is reminiscent of a sorites argument.

Assume that S?S? is a consistent extension of KT and provides the rule of margins. It follows that S?S? does not extend K4. The failure of what is clear always to be clearly clear is a striking result but one predicted by the epistemic theory of vagueness. (Sorensen [7], pp. 242–243 argues from the epistemic theory of vagueness and the vagueness of knowledge to the failure of the corresponding principle for knowledge.) It is harder to accommodate within the standard apparatus of supervaluations; this may be a version of the problem of higher-order vagueness (perhaps a hierarchy of valuations is required).

One way to realize these ideas would be to suppose that AA is clear at a world iff it is true at all nearby worlds on some appropriate metric. Perhaps AA is clear iff we are very reliably right about it, and reliability is a matter of leaving a margin for error, at least for sentences of the language in question (Williamson [8], pp. 103–108 offers a tentative defense of the epistemic theory along these lines). One would thus consider models ⟨W,R,V⟩\langle W,R,V\rangle with a metric dd defined on WW, where uRvuRv iff d(u,v)<kd(u,v)<k (u,v∈Wu,v\in W, k>0k>0). RR would therefore be reflexive and symmetric; conversely, every reflexive symmetric relation is induced by some metric in this way (to see this, put d(u,v)=0d(u,v)=0 iff u=vu=v, d(u,v)=1d(u,v)=1 iff uRvuRv but not u=vu=v, d(u,v)=2d(u,v)=2 otherwise; let k=2k=2). Thus KTB would be the strongest system valid for these models. It is satisfying that KTB provides the rule of margins.

Of course, KTB is not a plausible logic of clarity once undecidable propositions are taken into account. If Goldbach’s Conjecture (GC) is false, it is clearly false in the relevant sense, for a counterexample can be computed; by contraposition and bivalence, if GC is not clearly false, it is true. The B axiom says that if GC is true it is clearly not clearly false: but then it would be clearly true. The truth of GC should not entail its clear truth, for it might be true yet not even informally provable. The B axiom is implausible in the light of such examples. KT is a better candidate for the strict logic of clarity. However, KTB is the system that emerges when one idealizes away such phenomena and concentrates on what may be the main source of sorites paradoxes. On this view, the impossibility of identifying a cut-off point for AA can be explained. The last cases of AA are cases of AA near cases of ∼A\mathord{\sim} A, that is, they are cases of A&∼□AA\mathbin{\&}\mathord{\sim}□ A; but A&∼□AA\mathbin{\&}\mathord{\sim}□ A has no clear cases, for □(A&∼□A)□(A\mathbin{\&}\mathord{\sim}□ A) is a contradiction in any normal extension of KT. Thus nothing is clearly one of the last cases of AA.
