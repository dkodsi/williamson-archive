Rational Failures of the KK Principle

Timothy Williamson

In C. Bicchieri, R. Jeffrey and B. Skyrms (eds.), The Logic of Strategy (1999), 101–118. Oxford: Oxford University Press.

It is tempting to suppose that rational thinkers satisfy the KK principle that if one knows something, then one knows that one knows it.1 This essay investigates a variety of phenomena which cause the KK principle to fail. The failures are rational in the sense that they can be described within a framework on which thinkers know all the logical consequences of what they know. Of course, actual thinkers fail to draw all these consequences; the point of the idealization is that this failure of deductive closure is quite separate from, because not necessary for, the failure of the KK principle. A positive proposal will be made as to the logic of rational knowledge.

The technical framework for the discussion will be the standard possible-worlds semantics for modal logic, interpreted epistemically.2 It is intended radically to idealize the epistemic capacities of actual thinkers, with the aim of showing that not even this radical idealization removes all objections to the KK principle. Section 1 briefly rehearses some elementary epistemic logic; those familiar with such material should go straight to Section 2.

1. Epistemic Logic

There is a set WW of worlds, thought of as mutually exclusive and jointly exhaustive situations or outcomes (they need not specify features irrelevant to the purpose of the model). The propositions are the subsets of WW; a proposition PP is true in a world ww if and only if w∈Pw\in P. Thus negations are complements in WW, conjunctions are intersections, and so on. For a thinker SS in a world ww, worlds are of two kinds. Some are accessible or epistemically possible; the others are inaccessible or epistemically impossible. Accessibility is a relation RR between worlds; different thinkers may have different accessibility relations. SS is treated as omniscient about what is true at each world from a world-neutral point of view; what SS may not know is which world she is in. If the proposition PP is false in some world accessible from ww, it is false in a world that, for all SS in ww knows, is actual, so SS in ww does not know PP. Conversely, if SS in ww does not know PP, there must be a world accessible from ww in which PP is false, otherwise SS would not be perfectly rational. Thus SS in ww knows PP if and only if PP is true in every world accessible from ww. What SS knows in each world is determined simply by the pair ⟨W,R⟩\langle W,R\rangle. Any pair ⟨W,R⟩\langle W,R\rangle, where WW is a set and RR is a binary relation on WW, constitutes a frame. If several thinkers are in question, each has her own accessibility relation, so a frame ⟨W,{Ri}i∈I⟩\langle W,\{R_i\}_{i\in I}\rangle is needed, where {Ri}i∈I\{R_i\}_{i\in I} is an indexed set of binary relations.

A class of frames ⟨W,R⟩\langle W,R\rangle determines an epistemic logic. We start with the language of the propositional calculus, with propositional variables p,q,p′,q′,…p,q,p',q',\ldots, negation (¬\neg) and conjunction (&\mathbin{\&}). Disjunction (∨\vee) and implication (→\rightarrow) are defined in terms of ¬\neg and &\mathbin{\&} in the usual way. We then add a knowledge operator 𝐊{𝐊} to the language. If the frames are of the form ⟨W,{Ri}i∈I⟩\langle W,\{R_i\}_{i\in I}\rangle (II fixed), an indexed set of knowledge operators {𝐊i}i∈I\{{𝐊}_i\}_{i\in I} must be added; for simplicity, only one knowledge operator will be discussed. Any mapping [][\ ] of the propositional variables to propositions in a frame ⟨W,R⟩\langle W,R\rangle determines a mapping of all formulas in the language to propositions in ⟨W,R⟩\langle W,R\rangle by

[¬A]=W−[A][\neg A]=W-[A]

The epistemic logic LCL_C determined by a class CC of frames is simply the set of formulas valid in every frame in CC. (US), (Taut), and (MP) are what one would expect of any classical logic. (K) and (Nec) say, in effect, that if a conclusion follows from a (perhaps empty) set of premises, and every premise is known, then the conclusion is known. An epistemic logic satisfying those five constraints is normal.

If CC is the class of all frames, LCL_C is the weakest normal logic. More restricted classes of frames yield stronger logics. For example, if we require RR to be reflexive, we gain

(T)
⊢𝐊p→p\vdash {𝐊}p\rightarrow p

That is, one knows only what is true. All the frames considered in this paper are reflexive.

The transitivity of RR corresponds to the KK principle, known in modal logic as the S4 or 4 axiom:

(4)
⊢𝐊p→𝐊𝐊p\vdash {𝐊}p\rightarrow {𝐊}{𝐊}p

To state the correspondence more exactly: (4) holds in LCL_C if and only if for every frame ⟨W,R⟩\langle W,R\rangle in CC, RR is transitive. It may be helpful to rehearse the argument. Suppose that accessibility is transitive. If 𝐊p{𝐊}p is true in a world ww, then pp is true in every world accessible from ww, so by transitivity pp is true in every world accessible from a world accessible from ww, so 𝐊p{𝐊}p is true in any world accessible from ww, so 𝐊𝐊p{𝐊}{𝐊}p is true in ww. Conversely, suppose that yy is accessible from xx and zz from yy, but zz is not accessible from xx. Assign to pp the set of worlds accessible from xx. Thus pp is true in every world accessible from xx, but not in zz. Thus 𝐊p{𝐊}p is true in xx but not in yy, so 𝐊𝐊p{𝐊}{𝐊}p is not true in xx.

We can often use an idealized picture of knowledge to single out a class of frames, and explore the implications of the picture by identifying the epistemic logic determined by that class. To undermine the KK principle, we need non-transitive frames. However, we may begin with a picture of knowledge that singles out a class of transitive frames, for it helps to explain the appeal of the KK principle.

2. Appearance and Reality

The picture is that rational thinkers know everything about the way things appear to them, and nothing about anything else. For a given rational thinker SS, there is a function aa taking each possible world ww to the way things appear to SS in ww, a(w)a(w). SS is omniscient about this function and about its value for the actual world. Thus if SS is in ww, a world xx is epistemically possible just in case xx is the same in appearance as ww; xx is accessible from ww if and only if a(x)=a(w)a(x)=a(w). SS knows a proposition if and only if it is true in every world with the same appearance as the world SS is in. Thus accessibility is not just reflexive and transitive, but symmetric as well. We are therefore directed to look at frames ⟨W,R⟩\langle W,R\rangle where RR is an equivalence relation. The picture does not formally require any further constraints, for whevever RR is an equivalence relation, a function like aa can be defined.3 The logic determined by these frames is S5, the weakest normal logic satisfying (T) and

(5)
⊢¬𝐊p→𝐊¬𝐊p\vdash\neg {𝐊}p\rightarrow {𝐊}\neg {𝐊}p

The KK principle is derivable in S5. In effect, (5) says that if SS does not know something, she knows that she does not know it.

There are many objections to (5), even as a principle about rational knowledge. One problem is that it does not allow for the fallibility of the sources of knowledge. If rational thinkers are not to be embarrassingly ignorant, their empirical knowledge will be drawn from sources that occasionally deliver false beliefs. On excellent evidence, SS rationally believes the false proposition PP. Since PP is false, SS does not know PP. Now the evidence may be so good that SS rationally believes that SS knows PP (surely rational thinkers often know that they know an empirical proposition, and are therefore willing to believe that they know such a proposition). Thus SS fails to believe that she does not know PP, so SS fails to know that she does not know PP.4 (5) should be avoided. What this indicates about the picture of rational knowledge is that either rational knowledge can go beyond appearances or appearances can be false. Subtler objections to (5) use the idea that a rational thinker’s ability to discriminate between appearances may vary from world to world. These objections need not be pressed, for the failure of the system S5, and in particular of axiom (5), in the logic of rational knowledge will follow in any case from the failure of rational knowledge to satisfy the KK principle. But the objections above, even if accepted, do not undermine the KK principle. For that a different picture of knowledge is needed. Four phenomena will be investigated: plural knowledge; time delays; limited discrimination; margins for error.5

3. Plural Knowledge

The KK principle is traditionally formulated for single subjects. However, we may begin by rehearsing its familiar failure for a plurality of subjects. Suppose that Peter and Paul each toss a coin. Each sees which way up his coin landed, and has no idea which way up the other’s coin landed. Both men are rational and understand the structure of the situation. In fact, both coins landed heads. Neither Peter nor Paul is in a position to know that, of course, but each of them knows that at least one coin landed heads. However, Peter does not know that Paul knows that at least one coin landed heads; if Peter did know that, he could work out that Paul’s coin landed heads, for he knows that if Paul knows that at least one coin landed heads then Paul’s coin landed heads. Symmetrically, Paul does not know that Peter knows that at least one coin landed heads. Thus, although Peter and Paul know that at least one coin landed heads, Peter and Paul do not know that Peter and Paul know that at least one coin landed heads. As a plural subject, Peter and Pual fail the KK principle. They both know something, but they do not both know that they both know it; the knowledge they both have is not mutual or common between them. It is just such cases that the concept of common or mutual knowledge is designed to exclude. People have common knowledge of a proposition only if they all know it, they all know that they all know it, they all know that they all know that they all know it, and so on. If “they all know” satisfied the KK principle, this conjunction would collapse into its first conjunct.

For the sake of simplicity, Peter and Paul may each be assumed to satisfy the appearance/reality model of rational knowledge individually. There are just four worlds to consider, depending on the outcome of the two tosses. They form a set W={hh,ht,th,tt}W=\{hh,ht,th,tt\}; for example, htht is the world in which Peter’s coin lands heads and Paul’s coin lands tails. To Peter, worlds have the same appearance if and only if his coin lands the same way in them. His accessibility relation R1R_1 is an equivalence relation, partitioning WW according to the way his coin lands into the two equivalence classes {hh,ht}\{hh,ht\} and {th,tt}\{th,tt\}. The logic of “Peter knows” is S5; in particular, if Peter knows something, he knows that he knows it. Similarly, Paul’s accessibility relation R2R_2 is an equivalence relation, partitioning WW according to the way his coin lands into the two equivalence classes {hh,th}\{hh,th\} and {ht,tt}\{ht,tt\}. The logic of “Paul knows” is S5; in particular, if Paul knows something, he knows that he knows it.

In a world ww, it is false that Peter and Paul know a proposition PP if and only if either Peter fails to know PP or Paul fails to know PP, that is, if and only if, for some world xx, either wR1xwR_1x or wR2xwR_2x, where PP is false in xx. Contrapositively, in ww Peter and Paul know PP if and only if PP is true in every world xx such that either wR1xwR_1x or wR2xwR_2x. Thus Peter and Paul plurally have an accessibility relation RR; it is the disjunction of R1R_1 and R2R_2. The notion of a frame can be applied to plural knowledge if it can be applied to singular knowledge. For example, hhRhhhhRhh, hhRhthhRht and hhRthhhRth but not hhRtthhRtt. Similarly, htRhhhtRhh, htRhthtRht and htRtthtRtt but not htRthhtRth. RR is nontransitive, for hhRhthhRht and htRtthtRtt but not hhRtthhRtt; consequently, “Peter and Paul know” fails the KK principle. The underlying logical point is a simple one: the disjunction of two equivalence relations need not itself be an equivalence relation; in particular, it need not be transitive. Correspondingly, the conjunction of two operators each with an S5 logic need not itself have an S5 logic. The point generalizes to any number of rational thinkers. The accessibility relation for “each of them knows” is the disjunction of the accessibility relations for each of them. Even if each of the latter is an equivalence relation, the former need not be.6

What is the logic of plural knowledge, on the simplifying assumption that the logic of individual knowledge is S5? Equivalently, what follows about a relation given that it is the disjunction of a number of equivalence relations? The answer is rather complex, for combinatorial reasons, if we fix the number of individual thinkers, and so of equivalence relations. Matters are simpler if we ask for the logic of plural knowledge for a varying number of S5-like thinkers. Equivalently, what follows about a relation RR given that it is the disjunction of some equivalence relations, but nothing about how many? Since any disjunction of reflexive relations is reflexive, and any disjunction of symmetric relations is symmetric, it follows that RR is reflexive and symmetric. In fact, nothing more follows. We can show this by showing that if RR is reflexive and symmetric, it is a disjunction of equivalence relations. Treat RR as a set of ordered pairs. For each ordered pair ⟨x,y⟩\langle x,y\rangle, there is an equivalence relation RxyR_{xy} containing just the ordered pairs ⟨x,y⟩\langle x,y\rangle, ⟨y,x⟩\langle y,x\rangle and ⟨z,z⟩\langle z,z\rangle for each zz in the domain. RR is simply the disjunction of all RxyR_{xy} such that ⟨x,y⟩∈R\langle x,y\rangle\in R.

The logic of plural knowledge for a varying number of S5-like thinkers is thus determined by the class of reflexive symmetric frames. The axiom corresponding to symmetry is known, for no very good reason, as the Brouwerian axiom:

(B)
⊢¬p→𝐊¬𝐊p\vdash\neg p\rightarrow {𝐊}\neg {𝐊}p

(B) is valid in a frame ⟨W,R⟩\langle W,R\rangle if and only if RR is symmetric. On the present reading, (B) says that if a proposition is false then everyone knows that not everyone knows it. For each thinker SS satisfies the axiom by hypothesis (it is a theorem of S5), and so knows that she does not know the proposition, and deduces that not everyone knows it. If (B) is wrong for plural rational knowledge, it is wrong for singular rational knowledge. The logic of plural knowledge for a varying number of S5-like thinkers is the Brouwerian system KTB, the smallest normal epistemic logic satisfying (T) and (B).

The failure of the KK principle for plural knowledge can be generalized. In KTB, for any formula AA, ⊢A→𝐊A\vdash A\rightarrow {𝐊}A only in the trivial cases where ⊢A\vdash A or ⊢¬A\vdash\neg A.8 For example, the S5 axiom is not a theorem; not is the formula 𝐊np→𝐊n+1p{𝐊}^np\rightarrow {𝐊}^{n+1}p, where 𝐊n{𝐊}^n is a sequence of nn 𝐊{𝐊}s.

We now turn for the rest of the essay to failures of the KK principle for a single rational individual’s knowledge. When such failures occur, the thinker lacks common knowledge with herself.

4. Time Delays

Learning takes time. This is so even if we ignore (as we shall do) the time needed to make inferences. In order to know a fact, we have to react to it, and reaction takes time. This is obvious where learning involves causal interaction with the environment, but there are subtler applications of the same point. We can find one in a puzzle that worried Stoic philosophers. They asked whether the wise man must know that he is wise, and argued that he does not always do so. For consider the very first moment at which he was wise. He did not yet know that he was wise, for he had had no time to react to his wisdom. If he had believed that he was wise, that belief would have been formed in response to a time at which he was not wise; it would be an unwise belief, and fail to constitute knowledge.9 We might update the example by substituting the word “rational” for “wise,” and conclude that there is a time at which the rational man is rational and does not know it. The challenge to the KK principle is clear: at the moment when someone first knows something, how do they know that they know it, not having had time to react to their knowledge?

There is a small mathematical problem with the argument. Suppose that instants of time are ordered like the real numbers. If there is a last instant at which SS has never known PP, there is no first instant at which SS knows PP, for between any two instants a third intervenes. Thus SS can satisfy the principle that for any time at which SS knows PP there is an earlier time at which PP was true, even if SS has not always known that PP.10 This model always gives SS some time to react, but it requires SS to be able to react in arbitrarily short times. SS does not satisfy the principle that there is a positive length of time δt\mathrm{\delta} t such that, for any time tt, if at tt SS knows PP then PP was true at time t−δtt-\mathrm{\delta} t. Yet one might suspect that, for beings who cannot act faster than the speed of light, the latter principle is what is needed.

Those problems can be avoided by a simple model in which time is discrete; instants are ordered like the positive and negative integers. Assume, for simplicity, that SS can react to a fact with only an instant’s delay. The time delay principle in that case says only that if at time tt SS knows PP then at time t−1t-1 PP was true. We also require that if at time tt SS knows PP then PP is true at time tt, for SS knows only what is true (this is axiom (T)). The effect of time delays can best be seen if we idealize away from all other obstacles to knowledge, by imagining a rational thinker who takes in everything, but not instantaneously. This is to assume that it is sufficient as well as necessary for SS at tt to know PP that PP be true at both t−1t-1 and tt. This amounts to looking at a single frame ⟨W,R⟩\langle W,R\rangle with the integers (i.e., times) as worlds, where wRxwRx if and only if either x=wx=w or x=w−1x=w-1.

Since RR is nontransitive, the KK principle fails. For example, if pp is assigned the proposition true at all and only nonnegative points, that is, [p]={x:x≥0}[p]=\{x:x\geq0\}, then [𝐊p]={x:x≥1}[{𝐊}p]=\{x:x\geq1\} and [𝐊𝐊p]={x:x≥2}[{𝐊}{𝐊}p]=\{x:x\geq2\}; hence 𝐊p→𝐊𝐊p{𝐊}p\rightarrow {𝐊}{𝐊}p is false at 1. More generally, [𝐊np]={x:x≥n}[{𝐊}^np]=\{x:x\geq n\}, so the instance 𝐊np→𝐊n+1p{𝐊}^np\rightarrow {𝐊}^{n+1}p of the KK principle is false at nn. Each instant repairs one failure of the KK principle and introduces a new one at a higher level. Moreover, there is no time at which 𝐊np{𝐊}^np is true for every nn, so SS never has common knowledge with herself of this proposition. The frame also provides cases in which a proposition is sometimes known but never known to be known. For example, if [q]={0,1}[q]=\{0,1\} then [𝐊q]={1}[{𝐊}q]=\{1\} and [𝐊𝐊q]={}[{𝐊}{𝐊}q]=\{\}. More generally, if a proposition is false at a time, then at no later time on this model does SS have common knowledge with herself of the proposition.

As already indicated, the failure of the KK principle on the frame has nothing to do with the time needed to make inferences. As soon as the rational thinker in question knows a proposition, she knows all its logical consequences; that is guaranteed by the frame theoretic semantics. On the present picture, its interpretation is simply that, as soon as a fact obtains, so do all its logical consequences; thus the thinker has as much time to react to the consequences as to what they are consequences of.

Because each world has RR to at most two worlds, the logic of the frame can be shown to contain the following theorem:11

(#)
⊢𝐊(p→q)∨𝐊(p→¬q)∨𝐊p\vdash {𝐊}(p\rightarrow q)\vee {𝐊}(p\rightarrow\neg q)\vee {𝐊}p

The logic of the frame can be shown to be the weakest normal logic containing both (T) and (#), KT#.12 The failure of the KK principle can be generalized as before. In KT#, for any formula AA, ⊢A→𝐊A\vdash A\rightarrow {𝐊}A only if either ⊢A\vdash A or ⊢¬A\vdash\neg A.13 A gap between the times at which AA is true and the times at which it is known is ruled out only if AA must be either always true or always false.

We can avoid the strange principle (#) by using time delays over many instants. For example, we might consider a frame ⟨W,R⟩\langle W,R\rangle in which WW is the set of real numbers and wRxwRx if and only if w−1≤x≤ww-1\leq x\leq w. There are many other ways of realizing the general idea that wRxwRx if and only if xx is in an interval of fixed length up to ww. The logic of such frames is rather sensitive to their mathematical structure. However, in all such frames RR will have the property (sometimes known as connectedness) that if wRxwRx and wRywRy then either xRyxRy or yRxyRx (the former disjunct is realized if xx is not earlier than yy, the latter if yy is not earlier than xx). A frame has that property if and only if it validates this formula:14

(D1)
⊢𝐊(𝐊p→q)∨𝐊(𝐊q→p)\vdash {𝐊}({𝐊}p\rightarrow q)\vee {𝐊}({𝐊}q\rightarrow p)

Of course, (D1) will not survive the introduction of obstacles to knowledge beyond time delays.15

5. Limited Discrimination

Perfectly rational thinkers need not have perfect eyesight; their powers of discrimination are limited. Detailed examination of a typical case suggests that such limits typically involve failure of the KK principle. The case used here involves a time series, but the point could be made equally well for synchronic discrimination; time delays are no longer the issue.

Our rational thinker is monitoring the growth of a tree. Each morning she goes to see what progress it has made. 6. Margins for Error

The examples considered so far have all been characterized by logics with theorems that look too strong when interpreted in terms of rational knowledge: (**n_n), (B), (#), (D1). Moreover, if we tried to combine these axioms, we should find ourselves back with the KK principle. For example, accessibility is symmetric in any frame for (B) and connected (in a sense explained above) in any frame for (D1); but it is easy to show that any symmetric connected relation is transitive, so accessibility is transitive in any frame for both (B) and (D1).18 Yet the two axioms characterize different realizations of the same underlying intuition about margins for error. Time delays are essentially temporal margins for error, and validate (D1) when they are the only obstacles to knowledge; spatial margins for error like those in Section 4 validate (B) when they are the only obstacles. The question is what logic results from a less restrictive conception of the obstacles to knowledge.

The minimal logic for rational knowledge is KT, sometimes known as T, the weakest normal system containing axiom (T)—that is, the weakest in which knowledge entails truth and is closed under logical consequence. Might there be some additional principle in common between the stronger systems considered in Sections 2 to 4 that ought to be included in a logic for rational knowledge? We can show that there is no such principle if we assume that rational knowledge is subject to variable margins for error, by showing that KT is the logic for such knowledge. Thus, in determining the logic for rational knowledge, we need not consider any obstacle to knowledge beyond variable margins for error, since consideration of them already forces us to the minimal system.

A fixed margin for error principle has the following form: For every proposition PP of the relevant kind, PP is known in world ww only if PP is true in every world xx for which d(w,x)<εd(w,x)<\mathrm{\varepsilon}. Think of this as a schema, whose instances we specify by specifying the relevant kind of proposition, the metric dd, and the constant ε>0\mathrm{\varepsilon}>0. A variable margins for error principle has this form: For every proposition PP of the relevant kind, PP is known in world ww only if for some δ>0\mathrm{\delta}>0 PP is true in every world xx for which d(w,x)<ε+δd(w,x)<\mathrm{\varepsilon}+\mathrm{\delta}. A margin ε\mathrm{\varepsilon} wide is just not enough for safety, but anything wider will do.

If one puts ε=0\mathrm{\varepsilon}=0 in a variable margins for error principle, it says that PP is true at every world in some open neighbourhood of ww. This would express the idea that although the rational thinker’s knowledge cannot be perfectly precise, it can attain any degree of precision short of perfection. This idea is quite consistent with the KK principle, for if PP is true at every world in some open neighbourhood of ww, then for every world xx in that neighbourhood, PP is true in every world in some open neighbourhood of xx. Thus when a variable margins for error principle with ε=0\mathrm{\varepsilon}=0 is the only obstacle to knowledge, the KK principle holds. However, in many situations a rational thinker’s knowledge cannot be made arbitrarily precise. She cannot make her eyesight arbitrarily good just by concentrating hard enough. For situations of this kind we need ε>0\mathrm{\varepsilon}>0.

In effect, we have a family of accessibility relations RδR_{\mathrm{\delta}}, where wRδxwR_{\mathrm{\delta}} x if and only if d(w,x)<ε+δd(w,x)<\mathrm{\varepsilon}+\mathrm{\delta}; the formula 𝐊p{𝐊}p is true at ww if and only if, for some δ\mathrm{\delta}, the formula pp is true in every world xx such that wRδxwR_{\mathrm{\delta}} x.
